# 담다(Damda) — 동영상 다운로더 (goodseed AI LAB)

## 설치·실행 (윈도우, 3단계)
1. Python 설치: https://www.python.org/downloads/  → 설치 화면에서 **Add python.exe to PATH** 체크
2. `install.bat` 더블클릭 (yt-dlp, PySide6, ffmpeg 자동 설치 — 인터넷 필요)
3. `run.bat` 더블클릭

## 기능
- 영상·재생목록·채널 링크 → 큐에 추가, 동시 다운로드(기본 2개)
- 동영상(MP4, 화질 선택) / MP3(음질 선택)
- 일시정지 → 이어받기, 취소, 완료 항목 지우기
- 구독: 채널 등록 후 [새 영상 확인]으로 새 영상만 받기
- 설정: 저장 폴더, 자막, 재생목록 하위 폴더, 동시 다운로드 수

## Python 없는 PC에 나눠 주려면
`build_exe.bat` 더블클릭 → `dist\담다.exe` 하나만 전달

## 문제가 생기면
- 오류 메시지를 통째로 복사해 AI에게 "원인과 고치는 방법 알려 줘"
- 어제는 되던 게 오늘 안 되면: `pip install -U yt-dlp`
